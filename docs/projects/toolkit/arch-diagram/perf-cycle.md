## 系统边界

```
                         信任边界
        员工 / 上级 / HR 管理员        │     绩效系统
                                      │
   HR 主数据（外部，只接口） ─────────⇒│  同步作业（全量影子表 / 增量）
                                      │           ↓
   浏览器 / App  ──HTTP──▶ 网关        │     填报 / 审批服务
                    （鉴权·三维限流）  │           │
                                      │           ├── 写受理单（同步）
                                      │           ⇢ 队列 ⇢ 业务表消费
                                      │           ├── WS 信号（尽力而为）
                                      │           └── HTTP 拉待办（正确性）
                                      │
                                      │  MySQL 主从     Redis
                                      │  组织树 / 受理   令牌·计数打散
                                      │  业务表 / ADS    连接登记
                                      │
                                      │  调度 ──▶ 预计算 ──▶ 结果表
                                      │              ⇣ 可选
                                      │            Doris（二次聚合）
```

## 关键路径（压测对象）

| 路径 | 语义 | 对应 |
|---|---|---|
| 提交 | 同步校验 + 受理；业务表异步 | ADR-003、填报压测口径 |
| 待办到达 | 推信号，拉状态 | ADR-004 |
| 组织树刷新 | 增量快、全量对；读不经 HR | ADR-002 |
| 结算报表 | 预计算点查；未命中回明细 | 报表专题 |

## 单点与降级

| 点 | 风险 | 降级 |
|---|---|---|
| HR | 外部可用性 | 读本地树；增量暂停等全量 |
| 队列 | 积压 | 受理仍成功，状态页可查 |
| 长连接 | 网关 Upgrade / 连接表 | 短轮询（要单独限流） |
| 预计算 | 口径双写漂移 | 实时兜底必须永远可走 |

## 分叉（已抽 ADR）

- 同步要不要 CDC → ADR-002
- 截止前能不能 429 → ADR-003
- 推送能不能带状态 → ADR-004
