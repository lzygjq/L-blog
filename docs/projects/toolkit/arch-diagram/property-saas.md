图例：`→` 同步；`⇢` 业务消息（RocketMQ）；`⇒` 变更流（Kafka / CDC）。

```
   物业员工 / 业主 / 设备
            │
            ▼
     网关（鉴权·限流·租户识别）
            │ HTTP
            ▼
     框架 JAR（租户上下文、幂等、缓存约定）── 被业务服务依赖，禁止反向依赖
            │
     ┌──────┴──────┬────────────┐
     ▼             ▼            ▼
   账单缴费      门禁访客      社区交易     ……
     │             │            │
     │ 强一致写     │ 设备协议    │ 库存状态机
     ▼             ▼            ▼
   MySQL（L1 共享库+tenant_id / L2 Schema / L3 独立实例）
     │
     │ binlog
     ▼
   CDC ──⇒ Kafka ──▶ Doris（热/温分析）
                      └── TTL 校验后 ──▶ 对象存储 + Iceberg（冷）

   Redis（热点、锁、短队列）    调度（出账分片 + 执行权互斥）
```

## 边界

| 边界 | 含义 |
|---|---|
| 网关以里 | 已鉴权；租户必须已解析 |
| MySQL 与 Doris | 在线事务 vs 分析，禁止报表打回主库「顺便查」 |
| L1 / L2 / L3 | 隔离强度，不是三套业务代码 |
| 设备 | 弱网；开门正确性不能只活在云上 |

## 关键路径（将来压测对象）

缴费、团购抢购、门禁高峰、报表、全量推送。口径见[压测口径 · 物业容量](/projects/toolkit/perf-report/property-capacity)。

## 单点

| 点 | 备注 |
|---|---|
| 在线主库 | 写仍单主，主从不提高写吞吐 |
| CDC 位点 | 停久了超过 binlog 保留期只能全量 |
| 租户上下文 | 线程池 / 消费 / 定时任务断开即串租户 |
| 对象存储 | 冷查询尾延迟；不是热路径 |

## 分叉（已抽 ADR）

- 隔离一刀切还是分档 → ADR-005
- 分析要不要全家桶 → ADR-006
- 低频事件要不要独立 MQ → ADR-001（更早的脚手架约束，**不要**和本图 Kafka 变更流混成一次决策）
