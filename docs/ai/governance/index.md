# AI 治理：数据、评测、账单与退出

ROI、合规、效能三篇都还没回答这四句：代码和对话去了哪、幻觉进生产谁签字、推理账单谁承担、模型锁五年怎么退。五道闸门解决「这一次任务能不能交给 Agent」；效能 §五解决「个人变快不等于交付变稳」。本篇把试点收成**可运行的机制**——仍然不做组织编制、会计准则、合同诉讼判定。

> **主线：AI 的风险不在模型智商，在四笔账有没有主人。**
>
> 数据账、质量账、费用账、退出账。任一笔没有签字人，试点就还是个人爱好；四笔都有，才谈得上「用业务语言讲清这笔钱」。

ChatClient API、数字人接入、DORA 五项怎么算、等保定几级的原文，禁止在本篇展开。需要时回链。

## 一、问题场景：试点很亮，账单和事故一起来 {#why}

| 现场 | 闸门 / 效能已经管了什么 | 本篇要补的 |
|---|---|---|
| 把生产库 schema 贴进对话，云厂商按默认条款训练 | PR 评审拦的是代码，不拦**上下文里的数据** | 数据分级：什么能出域、是否允许训练 |
| 客服助手一本正经地给错金额，已对用户可见 | Agent 循环会停，但**停在用户看到之后** | 主链路必须有降级与人闸，评测不过不能切流 |
| 个人 Copilot 很爽，月度推理账单从实验科目溢出 | 「个人变快」已被[效能 §五](/cloud-native/cicd/engineering-metrics#ai-paradox)指出 | 单位成本（每千次 / 每座席 / 每 token）有预算科目 |
| 签约三年独家模型，价格翻倍无法换 | 自建 vs 采购的口径在[成本篇](/methodology/tech-cost-roi#build-vs-buy) | **模型与提示词与评测集的退出清单**要在签约前存在 |

## 二、数据出境与训练用途 {#data}

只回答工程上必须先写死的两问，**具体路径和阈值的判定走[合规 · 数据出境](/security/compliance-system#cross-border)，本篇不做法务结论。**

| 问 | 机制上要留下什么 | 常见自欺 |
|---|---|---|
| **这段上下文算哪一类数据？** | 分级：可公开 / 内部 / 个人与支付相关。后两类默认不出域、不进提示词全文 | 「反正厂商说加密了」 |
| **厂商能不能拿它训练？** | 合同与控制台开关：**默认拒绝训练**；例外要有有效期和范围 | 试用套餐的默认勾选没人看 |

辅助研发与接进产品是两条数据流，不要共用一份「可以」：

- **写代码的 Agent**：仓库、日志、配置、客户样本。能进上下文的清单要白名单化；密钥与证件号走现有[脱敏](/java/spring/spring-boot/logging#hygiene)纪律。
- **进主链路的模型调用**：用户输入、检索命中的文档、工具返回值。RAG 必须元数据过滤，否则是跨租户泄露——见 [Spring AI · RAG](/ai/spring-ai/#rag)，本篇不写切块策略。

出域一旦发生，删除主库解决不了副本（对话日志、厂商侧保留、评测集）。这一点与[加密与合规边界](/security/crypto-compliance)里「删了不等于没了」是同一条，不重复手段清单。

## 三、评测与人闸 {#eval}

[五道闸门](/ai/vibe-coding/#five-gates)管的是**研发流程**（规格、粒度、PR、CI、分阶段发布）。主链路还要多两道，专门挡「模型这次说错了」：

| 闸 | 挡什么 | 签字 |
|---|---|---|
| **上线前评测** | 固定集上的正确率 / 拒答率 / 越权率；**不过线不能切流** | 业务 owner 认「这组题代表线上」 |
| **在线人闸** | 资金、权限、承诺类输出必须人确认或走规则引擎，不走模型终态 | 与[人的介入点](/ai/vibe-coding/#human-gates)同一类：边界逻辑不放手 |
| **失败降级** | 超时、拒答、评测漂移：切规则、切人工、切只读，**业务必须仍能完成主路径** | 架构师认「LLM 挂了用户看到什么」——这正是 L3 附读那一问 |

Human-in-the-Loop 在编排里是一个节点，在组织上是免责边界，见 [Spring AI Alibaba · Graph](/ai/spring-ai-alibaba/#graph)。本篇只要这句话：**没有降级路径的主链路，等于把可用性交给模型供应商的 SLA。**

评测集本身是数据。生产对话进评测集，要按第二节分级，不要用真实证件号当回归用例。

## 四、推理账单：单位经济学 {#bill}

「AI 很贵」无法决策。能决策的是**每单位产出的成本**，口径与[单位经济学](/methodology/tech-cost-roi#unit-economics)相同，只是单位换成 AI 的：

| 单位 | 适用 | 不要用的口径 |
|---|---|---|
| **每千次调用** | 检索、分类、抽取 | 只报 token 单价（隐藏了重试与上下文长度） |
| **每座席 / 每员工月** | Copilot、客服辅助 | 只报「席位数」，不含实际采纳率 |
| **每成功任务** | Agent 闭环 | 只报会话数（失败会话一样计费） |

三条防自欺（从成本篇搬过来的 AI 版）：

1. **重试、工具回环、长上下文要进分母。** 一次用户可见成功，背后可能是十几次补全。
2. **个人加速不是交付加速。** 账单涨了而变更失败率也涨，总账是负的——见[效能 §五](/cloud-native/cicd/engineering-metrics#ai-paradox)。
3. **实验科目要有封顶。** 没有预算科目的试点，会在「先用着」里变成固定成本。

谁付钱：产品调用走产品预算；研发 Copilot 走工程效能预算。混在一堆「云账号」里，四问里的「谁付钱」永远答不清，见[方案评审 · 四问](/projects/toolkit/review/#four-questions)。

## 五、锁定与退出 {#exit}

模型供应商适用[自建 vs 采购](/methodology/tech-cost-roi#build-vs-buy)的同一套规则：**同周期、同口径、把退出成本算进签约前。** 本篇只补 AI 特有的锁定物：

| 锁定物 | 退出时要带走什么 | 签合同时就要有的条款 |
|---|---|---|
| **权重与 API** | 提示词、工具签名、评测集、回归阈值 | 数据导出、训练排除、价格调整通知期 |
| **上下文里的语料** | 对话与检索文档的删除证明 | 保留期、删除接口、 subprocessors |
| **微调件** | 能否导出；不能则当沉没成本 | 微调是否绑死账号与区域 |
| **编排与账号** | 流程能否在另一家模型上复现 | 抽象层是否已放在[Spring AI 定位](/ai/spring-ai/#positioning)那一层，而不是厂商 SDK 铺满业务 |

判断锁定的两个问题与成本篇相同：换供应商要多久、并行期付几份钱。答不出就还没到签字。**锁五年独家且评测集不能出门，等于把第 1 问的降级路径也锁死了。**

组织、财务、法务怎么批合同，本站不写。这里只要求技术侧能交出：评测集可携、抽象层可替换、退出成本有数字。

## 六、谁签字（四笔账） {#owners}

| 账 | 日常主人 | 例外谁拍 |
|---|---|---|
| 数据与训练 | 安全 / 合规对接人 | 出域或允许训练 |
| 评测与降级 | 该功能的业务 owner + 架构 | 无降级的主链路 |
| 推理账单 | 产品或效能对应预算科目 | 超预算、把实验科目转固定 |
| 退出与锁定 | 架构 + 采购口径 | 独家、超三年、微调不可携 |

没有名字的格子，等于试点还不能叫治理。

## 七、面试口径 {#interview}

| # | 问题 | 一句话答案 |
|---|---|---|
| 1 | AI 治理要管哪四笔账？ | 数据与训练用途、评测与人闸、推理单位成本、供应商退出。任一笔没有主人就还是试点 |
| 2 | 生产数据能不能进提示词？ | 按分级。个人与支付相关默认不出域、不进全文；厂商训练默认关。路径与阈值回合规篇，本篇不判定 |
| 3 | 五道闸门够不够挡主链路幻觉？ | **不够。** 闸门管研发流程；主链路还要上线前评测、在线人闸、失败降级 |
| 4 | LLM 挂了业务怎么办？ | 必须能说出降级成规则、人工还是只读。没有降级就是把可用性外包给模型 SLA |
| 5 | 怎么算 AI 贵不贵？ | 用每千次 / 每座席 / 每成功任务，把重试和长上下文算进分母。不要只报 token 单价 |
| 6 | 个人写代码变快为什么交付可能变慢？ | 返工与评审被账单和变更失败率吃回去，见效能 §五 |
| 7 | 模型锁三年独家最大的技术风险是什么？ | 评测集与提示词带不走，降级路径也锁死。退出成本必须进签约前 TCO |
| 8 | 治理和法律意见差在哪？ | 本篇只要求机制与签字人。路径是否合法、合同条款、诉讼——走专业渠道，站点不转述判定 |
