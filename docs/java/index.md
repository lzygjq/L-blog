## 阅读建议

**优先级排序**：如果时间有限，建议按 **Spring 生态 → 设计模式 → 并发 → JVM → 测试与质量 → Java 基础** 的顺序阅读。

理由：Spring 与设计模式是**面试出现频率最高、且最容易答得浅**的两块——大多数候选人能说出"什么是 AOP"，但说不清"代理在生命周期的哪个阶段生成";能列出 23 种模式的名称，但说不清"策略和状态的边界在哪"。这两块的深度直接决定面试评级。

而 Java 基础与并发是**长期基本功**，需要持续投入，适合按节奏推进而非突击。

**测试与质量排在第五**，是因为它的价值取决于**你有没有可被验证的产出**。同样一句「我用 Testcontainers 做集成测试」，做过的和没做过的人，被追问三层就分得出来——所以这一块适合在项目推进过程中同步补，而不是纯读。

## 面试高频

并发（AQS/线程池）、JVM（GC 调优实战）、Spring（IoC/AOP/循环依赖/事务传播）、测试（Mock 边界 / 切片选择 / 覆盖率口径）。

> **各板块的面试高频清单见对应板块的导览页**——每篇导览都按出现频率排了序，可直接当复习清单用。
