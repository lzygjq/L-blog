# Java 核心 · 板块导览

Java 是整个知识体系的主干，按「基础 → 并发 → JVM → Spring 生态 → 设计模式」的顺序递进。

## 学习主线

| # | 板块 | 内容 | 状态 |
|---|---|---|---|
| 1 | [Java 基础](/java/basics/) | 泛型、反射、注解、IO/NIO、新特性 | 写作中 |
| 2 | [Java 集合](/java/collections/) | 数据结构与复杂度、`ArrayList` 源码与扩容、`HashMap` 原理与扩容（**4 篇已成篇**） | 部分完成 |
| 3 | [并发与 JUC](/java/concurrent/) | 线程基础、线程安全与 JMM、CAS 与原子类、AQS 与锁、线程池、并发容器、ThreadLocal（**8 篇已成篇**） | 部分完成 |

## 阅读建议

**优先级排序**：如果时间有限，建议按 **Spring 生态 → 设计模式 → 并发 → JVM → Java 基础** 的顺序阅读。

理由：Spring 与设计模式是**面试出现频率最高、且最容易答得浅**的两块——大多数候选人能说出"什么是 AOP"，但说不清"代理在生命周期的哪个阶段生成";能列出 23 种模式的名称，但说不清"策略和状态的边界在哪"。这两块的深度直接决定面试评级。

而 Java 基础与并发是**长期基本功**，需要持续投入，适合按节奏推进而非突击。

## 面试高频

并发（AQS/线程池）、JVM（GC 调优实战）、Spring（IoC/AOP/循环依赖/事务传播）。

> **各板块的面试高频清单见对应板块的导览页**——每篇导览都按出现频率排了序，可直接当复习清单用。
