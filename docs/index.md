## 仓库：按领域查

顶部六个板块是手册。同一篇既可能被成长 L1 读「会用」，也被成长 L3 读「代价是什么」。**不要把某一板块从头读到尾当成一条成长路线。**

| 板块 | 干什么 |
|---|---|
| [计算机基础](/fundamentals/) | 网络 / 操作系统 / 算法 |
| [语言与框架](/java/) | Java、Spring、测试；[大前端](/frontend/) |
| [数据与存储](/database/) | MySQL / Redis / 分片；[搜索](/search/)；[数仓](/bigdata/) |
| [中间件与分布式](/middleware/) | 消息、RPC；[分布式理论](/distributed/) |
| [架构与云原生](/cloud-native/) | 容器与编排、可观测；方法论 / 高可用 / 安全在相邻目录 |
| [实战与面试](/projects/) | 两条路线、工具箱、两个案例、[AI](/ai/)、[面试](/interview/) |

站点怎么组织、读到哪停、哪里故意不写，见[关于本站](/about/)。手头系统现在在哪一档，见[层账](/projects/architecture-evolution/ledger/)。
