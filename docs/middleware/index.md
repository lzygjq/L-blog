# 消息队列 · 板块导览

消息队列板块聚焦「可靠性、顺序性、幂等性」三条主线，并做横向选型对比：

- [RabbitMQ](/middleware/rabbitmq/)：Exchange 模型、可靠性投递、死信与延迟队列
- [RocketMQ](/middleware/rocketmq/)：事务消息、顺序消息、幂等设计，与 RabbitMQ/Kafka 对比
- [物联网 MQTT](/middleware/mqtt/)：协议要点（QoS/会话/遗嘱）、EMQX 部署、设备场景主题设计

## 面试高频

消息丢失与重复消费、事务消息实现、顺序消息保障、消息积压处理。

缓存相关主题见[数据存储板块](/database/redis/)。
